# 🎓 Django CGPA Calculator

A responsive Django web application to calculate CGPA based on course credits and letter grades.

## 🚀 Features
- Dynamic addition/deletion of subject rows using JavaScript.
- Custom grading scale matching university standards.
- Vibrant, modern gradient UI.
- Robust input handling and error prevention.

## 🛠️ Built With
- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite3
